# QALA — Аким на 5 часов

AI-симулятор городского управления для трека **Astana Innovations**, HackAlem AI. Пять решений, бюджет 100 единиц и проверяемая оценка качества городской среды.

## Быстрый запуск

Требуется Node.js 22.12+ (проверено на Node.js 24).

```bash
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Нажмите **«Посмотреть пример» → «Рассчитать сценарий»**. Ожидаемый Score: **56,54307** (на экране 56,54), бюджет 95/100.

Для AI-анализа скопируйте `.env.example` в `.env.local`, укажите `OPENAI_API_KEY` и перезапустите сервер. Без ключа доступны все расчёты, проверенные альтернативы и явно обозначенный разбор по правилам модели. Ключ используется только на сервере.

## Реализовано

- Каталог 14 мер, 5 районов, 10 показателей; ограничения бюджета, повторов, направлений и совместимости.
- Точный Score с лагами, синергиями, штрафами и поддержкой слабейшего района.
- Вклад мер по Шепли и полный перебор допустимых замен одного решения.
- OpenAI Responses API: структурированный анализ со ссылками на расчётные факты.
- Сравнение сценариев, локальное сохранение, ссылки на сценарий и экспорт JSON.
