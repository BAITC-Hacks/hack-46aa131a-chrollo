# География карты

Карта использует реальные полигоны OpenStreetMap, полученные через Nominatim 23 сентября 2026 года. Рендеринг — Leaflet; фон с улицами и рекой — стандартные тайлы OpenStreetMap. На карте показаны учебные показатели из датасета организаторов, а не фактические городские измерения.

В датасете пять районов. Поэтому геометрии нынешних Алматы и Сарайшыка объединены для слоя «Алматы». Это явно указано под картой. Полученная карта представляет территории модели и не заявляется актуальной картой административного деления.

| Район модели | Отношения OpenStreetMap                                                                                                           |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| Сарыарка     | [3486954](https://www.openstreetmap.org/relation/3486954)                                                                         |
| Байконур     | [8593081](https://www.openstreetmap.org/relation/8593081)                                                                         |
| Алматы       | [3482819](https://www.openstreetmap.org/relation/3482819), [19733918 — Сарайшык](https://www.openstreetmap.org/relation/19733918) |
| Нура         | [20593940](https://www.openstreetmap.org/relation/20593940)                                                                       |
| Есиль        | [3479876](https://www.openstreetmap.org/relation/3479876)                                                                         |

Геометрия хранится локально в [`src/data/astana-districts.json`](../src/data/astana-districts.json). Координаты WGS84 слегка упрощены с сохранением топологии для отображения. Скрипт подготовки проверяет валидность геометрии, положение в Астане и попадание подписей внутрь районов. Приложение не обращается к Nominatim при работе пользователя.

Данные и их адаптация распространяются по [Open Database License, ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Атрибуция: **© OpenStreetMap contributors**. [Авторские права и условия OSM](https://www.openstreetmap.org/copyright). На карте атрибуция остаётся видимой. Фон загружается браузером по [правилам сервиса тайлов](https://operations.osmfoundation.org/policies/tiles/), без массового скачивания и предварительной загрузки.

При недоступном интернете остаются локальные полигоны, выбор районов, баллы и расчёты; может отсутствовать фон улиц. Фоновый сервис не имеет гарантированной доступности.

Для обновления геометрии нужен Python с Shapely; для обычного запуска проекта они не требуются:

```bash
python -m pip install shapely
python scripts/prepare-map.py
npx prettier --write src/data/astana-districts.json
```

Если существует `.local/astana-districts-raw.json`, скрипт использует локальную копию. Без неё он делает последовательные запросы к Nominatim с интервалом более секунды.
