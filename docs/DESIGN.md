# Дизайн рабочего пространства QALA

Задача экрана: обсуждать городские решения и сразу видеть последствия, не теряя текущий план. Пользователь — участник симулятора и аналитик, которому нужно сравнение, а не вступительная страница.

## Компоновка

Компактная верхняя навигация освобождает ширину. Город занимает основную область; разговор остаётся рядом. На небольших экранах области складываются вертикально. Карта показывает исходный, текущий либо предлагаемый сценарий с явным названием состояния. Предпросмотр никогда не означает применение.

```text
QALA        Город и помощник · Меры · Отчёт         состояние AI
Название сценария                               управление
┌───────────────────────────────────┬─────────────────────┐
│ Score · бюджет · дефициты          │ Диалог              │
│ Большая карта районов              │ Задача → проверки   │
│ Показатель / до / после            │ → вывод             │
│ Выбранный район и изменения        │                     │
├───────────────────────────────────┤                     │
│ Условия · варианты · эксперименты  │ Поле сообщения      │
└───────────────────────────────────┴─────────────────────┘
```

## Визуальная система

- Фон: mist `#f5f7f4`; поверхности: paper `#ffffff`.
- Текст: forest `#233b32`; вторичный текст: slate `#68776f`.
- Действия и улучшения: green `#245f49`; дефициты: clay `#a94c41`.
- Река: muted blue `#a9cbd0`; оттенки районов передают выбранный показатель.
- Manrope: заголовки 28–34, текст 14–15, подписи не мельче 12 для рабочих данных. IBM Plex Mono: баллы и изменения.

Главная визуальная особенность — крупная интерактивная схема районов: цельные области, читаемые подписи и изменения. Геометрия остаётся условной и подписана; реальные границы или географическая точность не заявляются.

## Взаимодействие

AI самостоятельно подбирает и проверяет варианты. Пользователь явно выбрал применение итогового плана по кнопке. Активный предпросмотр маркируется, возвращение к текущему плану доступно сразу. Условия и проверки раскрываются по необходимости, а не занимают первый экран постоянно.

Markdown поддерживает абзацы, списки, выделение, ссылки, код и таблицы. HTML и внешние картинки из ответов не исполняются. Клавиатурный фокус видим, таблицы прокручиваются, движение уважает reduced motion.
