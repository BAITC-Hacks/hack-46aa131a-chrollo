# Воспроизводимый пример: от запроса к компромиссу

## Без API-ключа

```bash
npm ci
npm run demo:verify
npm run dev
```

Откройте http://127.0.0.1:3000.

1. «Обзор города» → «Посмотреть пример» → «Рассчитать сценарий». Бюджет **95**, Score **56,54**, критических показателей **0**.
2. «Город и AI» → «Условия поиска» → «Подобрать планы». Без закреплений и исключений проверяется **694 395** допустимых вариантов. Лучший общий Score: **57,236735**. Он появляется в предпросмотре; принятый план остаётся прежним.
3. Переключите вариант «Самый слабый район» над картой. Минимальная районная оценка **55,2625**, официальный Score **55,43026**, **2** критических показателя. Рост районного балла не гарантирует рост общей оценки: штрафы учитываются отдельно.
4. Нажмите «К принятому», откройте условия и закрепите школу и поликлинику из примера. Повторите поиск. Все найденные планы обязаны сохранить обе меры и район Нура. Смена цели не отменяет закрепления.
5. В отчёте текущего сценария откройте «Если сроки сдвинутся», выберите **3 квартала** и **Семейная поликлиника**. Score эксперимента **55,30514**, медицинский показатель Нуры **38,5**, критических значений **1**. Бюджет остаётся **95**.

## С OpenAI

После настройки `.env.local` и перезапуска сервера:

1. Загрузите пример из задания и откройте «Город и AI». Если остался старый диалог, нажмите «Новый диалог».
2. Напишите: **«Сохрани школу и поликлинику, улучши остальное»**. В «Условиях поиска» должны закрепиться только эти две меры в Нуре.
3. Продолжите: **«Теперь помоги самому слабому району»**. Цель меняется; закрепления сохраняются.
4. Напишите: **«Сними все закрепления и помоги самому слабому району»**. Закрепления исчезают, первым показывается вариант с минимальной районной оценкой **55,2625**.
5. Спросите: **«Почему у этого варианта общий Score ниже?»**. Модель получает повторно рассчитанные факты и правила для объяснения компромисса.
6. Нажмите **«К принятому»**, чтобы вернуться к примеру организаторов, затем напишите: **«Что если поликлиника задержится на три квартала?»**. На карте появится эксперимент: **55,30514**, медицина Нуры **38,5**. Нажмите «Без задержки», чтобы вернуться к номинальному результату.

Числа плана и эксперимента определяются кодом. Формулировка свободного ответа LLM может различаться. Условия доступны под картой. Вопросы относятся к открытому предпросмотру или эксперименту — контекст подписан над полем ввода. Рекомендация никогда не меняет сценарий сама. На телефоне карта и чат переключаются вкладками.
